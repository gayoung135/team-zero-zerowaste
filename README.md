# ZEROWASTE (팀명: ZERO)
> **웹캠 모션 인식을 활용한 분리배출 아케이드 게임 및 가상 테라리움 육성 서비스**

본 프로젝트는 자원 순환과 환경 보호를 주제로 한 교육 및 체험형 게임입니다. 플레이어가 웹캠을 통해 직접 행동하고 체험하며 즐겁게 몰입할 수 있도록 설계된 Unity 기반 프로토타입입니다.

---

## 👥 팀원 및 역할 분담
* **박가영 (PM):** 프로젝트 관리/기획/시스템 구조 설계, 게임 디자인, 도감/회원가입/로그인 구현
* **김나연 (Unity / AI):** MediaPipe 활용 실시간 손 인식(Hand Tracking) 구현, 테라리움 상점 구현
* **유이현 (Unity / Game):** Unity 게임1, 2 엔진 코어 개발, 쓰레기 낙하 및 충돌 판정 물리 로직 구현
* **양혜인 (Unity / assistant):** 그래픽 및 사운드 에셋 리서치, 테라리움 메인 홈

---

## 주요 기능 (Core Features)

### 1. 웹캠 기반 쓰레기 분류 게임 1 - Catch & Drop
* 웹캠을 통해 실제 손을 인식(MediaPipe Hands)합니다.
* 화면 위에서 내려오는 가상 쓰레기를 손으로 잡아 올바른 분리수거 통에 드래그하여 골인시킵니다.
* 제한 시간 내에 올바르게 분류하여 점수(Score)를 획득하는 아케이드 모드입니다.

### 2. 웹캠 기반 쓰레기 분류 게임 2 - Swipe
* 화면에서 컨베이어 벨트에서 나오는 가상 쓰레기를 좌우로 밀어서 올바른 분리수거 통으로 나눕니다.

### 3. 가상 정원 꾸미기 (Terrarium) & 에코 상점
* 게임 플레이를 통해 획득한 재화(에코 포인트)를 활용합니다.
* 에코 상점에서 식물, 돌, 유리병, 배경 등의 아이템을 구매합니다.
* 나만의 가상 작은 정원을 커스터마이징하며 성취감과 힐링을 유도합니다.

### 4. 쓰레기 수집 도감
* 게임 플레이를 통한 쓰레기 정보를 얻어 도감을 활성화합니다.

## 🚨 프로젝트 실행 및 주의 사항
1. 본 프로젝트는 **웹캠(Webcam)** 장치가 필수적으로 필요합니다.
2. 실행 시 카메라 권한을 반드시 허용해 주셔야 손 인식 플레이가 가능합니다.
3. (예외 처리) 웹캠을 허용하지 않거나 카메라가 없는 환경의 경우, **키보드 및 마우스**로 대체 조작이 가능합니다.
